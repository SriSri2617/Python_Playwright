### Topics Covered

1. Regular Expressions (Regex)

    - Practised regex patterns using Regex101.
    - Matched text patterns such as:
    - Dates (ISO 8601)
    - Postal codes
    - Email addresses
    - Monetary values
    - Length measurements



2. User Stories

    Created user stories and test scenarios for the Agile Helper web application and automated them using Playwright end-to-end tests.


    Examples include:

        - Viewing Agile Helper information.
        - Switching the page language to English.
        - Reading Sprint Planning instructions.
        - Reading Daily Standup instructions.
        - Navigating between different sprint days.
        - Reading Sprint Review and Sprint Retrospective information.

3. End-to-End Testing with Playwright


    Implemented automated UI tests using:
       - Python
       - Pytest
       - Playwright

The tests verify:

        - Page loading and title validation.
        - Language switching.
        - Navigation between sprint days.
        - Sprint Planning functionality.
        - Daily Standup functionality.
        - Sprint Review functionality.
        - Sprint Retrospective functionality.
        - Dialog visibility and closing behaviour.
        - Timer and meeting interactions.


Tools Used

        - Regex101
